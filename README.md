# java-lotto-precourse

## 프로젝트 개요

간단한 로또 발매기를 구현하는 미션입니다.
사용자는 구입 금액을 입력하고, 그에 해당하는 개수의 로또를 발행받습니다.
이후 당첨 번호와 보너스 번호를 입력하면 당첨 내역 및 수익률이 출력됩니다.
- JDK 21 버전에서 실행
- camp.nextstep.edu.missionutils의 Randoms, Console API 사용
- System.exit() 사용 금지
- 들여쓰기 깊이 2 이하, 메서드 길이 15라인 이하
- if-else, switch, 삼항 연산자 사용 금지
- 모든 상수 및 메시지 하드코딩 금지 (Constants, Message 클래스 사용)

## 기능 목록

1. 구입 금액 입력

- 사용자로부터 구입 금액을 입력받는다.
- 금액은 1,000원 단위여야 한다.
- 잘못된 입력 시 [ERROR]로 시작하는 메시지를 출력하고 다시 입력받는다.

2. 로또 방행

- 1~45 범위의 중복되지 않은 6개의 숫자로 로또를 발행한다. 
- 구입 금액에 따라 로또 개수를 계산하고 해당 개수만큼 로또를 발행한다.
- 발행된 로또 번호는 오름차순으로 출력한다.

3. 당첨 번호 입력

- 쉼표(,)로 구분된 6개의 당첨 번호를 입력받는다.
- 중복된 번호가 있으면 [ERROR] 출력 후 재입력한다.
- 번호가 1~45 범위를 벗어나면 [ERROR] 출력 후 재입력한다.

4. 보너스 번호 입력

- 보너스 번호 1개를 입력받는다.
- 보너스 번호가 당첨 번호와 중복되면 [ERROR] 출력 후 재입력한다.
- 보너스 번호가 1~45 범위를 벗어나면 [ERROR] 출력 후 재입력한다.

5. 당첨 내역 계산

- 구매한 로또와 당첨 번호를 비교하여 일치 개수를 계산한다.
- 보너스 번호 일치 여부를 판단한다.
- 일치 개수와 보너스 번호 여부에 따라 등수를 결정한다.
- 각 등수별 당첨 횟수를 집계한다.

6. 결과 출력

- 등수별 당첨 개수와 상금을 출력한다.
- 총 수익률을 계산하여 소수점 첫째 자리에서 반올림한다.
- 출력 형식은 요구사항의 예시와 정확히 일치해야 한다.

7. 예외 처리

- 모든 예외 상황은 IllegalArgumentException으로 처리한다.
- 에러 메시지는 반드시 [ERROR]로 시작해야 한다.
- 에러 발생 시 해당 단계부터 재입력받는다.
- 프로그램 종료 시 System.exit() 호출 금지.

## 사용된 상수 관리

- 문자열, 숫자 하드코딩을 금지하고 의미 있는 상수명으로 관리했습니다.

## 단위 테스트

- LottoNumberTest : 번호 범위(1~45) 유효성 검증
- LottoTest : 로또 번호 6개, 중복 금지, 정렬 확인
- WinningLottoTest : 중복 번호 및 보너스 중복 검증
- RankTest : 등수 판정 및 순서 확인
- LottoResultTest : 전체 로또 결과 계산 및 수익률 검증
